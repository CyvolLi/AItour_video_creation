# 演示带货 UI 细调设计

## 目标

依据三张 UI 参考图细调现有演示带货页面，保持纯前端、无真实交易、无本地商品图片。重点提升内容详情、横屏视频商品条和发布页商品预览的视觉层级，不新增独立商城页面。

## 页面映射

### 内容详情 `pages/detail`

采用参考图一的同屏信息结构，取消上一版三 Tab：

1. 浅绿色页面背景与顶部圆角标题区。
2. 视频、作者、标题、正文、标签/时间集中在主内容卡内。
3. “使用同款绑定卡片”作为主按钮。
4. 主按钮下显示一条横向“乡村市集”演示商品条，包含公开远程图片、商品名、卖点、价格、模拟销量和“+ 好物购”标签；点击只弹演示提示。
5. 点赞、收藏、评论统计紧随其后，评论列表和输入框保持同屏，不再由 Tab 隐藏。
6. 非视频卡片详情保持原功能，只统一背景、圆角和间距，不强加商品条。

### 视频生成结果 `pages/v_output`

参考图三调整层级，但保留横屏视频内部商品条：

- 商品条使用 `cover-view` 放在视频底部偏左，仅播放时显示，暂停/结束隐藏。
- 半透明白色底框、紧凑高度，不铺满画面；商品缩略图、名称、演示价和短 CTA 保持单行。
- 商品条位于原生视频控制栏上方，避免遮住进度、全屏和中央播放按钮。
- 文案、标签、下载/发布/重新生成按钮统一圆角、间距和浅绿色层级，减少大块阴影。
- 不新增真实购买、橱窗或交易跳转。

### 发布页 `pages/publish`

保留现有“选择代言商品（演示）”开关和稳定选品算法，仅按参考图二细调商品预览：

- 图片占比增大，白色圆角卡、红色演示价格、模拟销量和“乡村市集”标签。
- 明确“智能匹配，仅演示，不影响发布”。
- 发布 payload 保持原字段集合，不加入商品字段。

## 视觉系统

- 页面背景：浅薄荷绿与浅青渐变。
- 面板：白色或半透明白色，`24–36rpx` 圆角，轻阴影。
- 重点色：青绿色按钮，橙红色价格，红色“乡村市集”标签。
- 商品图片继续使用 `images.unsplash.com` 固定 HTTPS 链接，不新增图片文件。
- 远程图容器使用统一浅灰绿背景作为加载失败时的基础占位。

## 交互边界

- 商品条、商品卡、“好物购”等点击行为统一为 `wx.showToast` 演示提示。
- 不调用 `store-product`、小程序跳转、购物车、订单或新后端接口。
- 视频商品条继续由 `play/pause/ended` 控制显隐。
- 评论、收藏、视频保存、发布等原有功能保持不变。

## 测试与验收

- 页面级测试验证详情页无三 Tab、商品横条和评论同屏。
- 视频结果页测试验证播放状态显隐、半透明纯色底框以及不使用 `cover-view` 不支持的样式。
- 发布页测试验证预览视觉结构和 payload 不变。
- 全量 Node 测试、JS/JSON 检查和 `git diff --check`。
- Android/iOS 真机检查视频商品条不遮挡人物主体与 controls、详情页滚动、评论输入和发布页底部 dock。
