# Script 页面视觉对齐设计

## 目标

根据 `reference/UI_Image/script.png` 的参考图，对 `miniprogram/pages/script/script` 页面进行视觉样式对齐。

## 范围

- 保留现有脚本请求、脚本编辑、后续流转的页面逻辑
- 重做 `script` 页顶部标题区、脚本编辑卡片、操作按钮、底部 dock 的视觉样式
- 补齐与参考图一致的返回按钮和标题胶囊布局

## 设计方向

- 风格：奶油薄荷卡片风
- 背景：上浅绿、下浅青的柔和渐变
- 顶部：左侧圆形返回按钮 + 居中暖白标题胶囊
- 主体：大号白色圆角脚本编辑卡片
- 操作区：两个垂直排列的白色胶囊按钮
- 底部：白色悬浮 dock + 青色圆形图标按钮

## 结构说明

- 页面主体维持可滚动容器，避免长脚本被遮挡
- 逻辑上保留 `scriptContent` 双向绑定
- 视觉上将原先玻璃拟态样式改为实色卡片样式

## 验证方式

- 使用 `git diff --check` 做静态检查
- 在微信开发者工具中对照 `reference/UI_Image/script.png` 做视觉比对
